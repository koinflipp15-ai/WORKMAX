MAX — Кадровый агент (одностраничный сайт)

Файлы:
- index.html — структура страницы
- style.css — чёрно-золотой дизайн, адаптивность и CSS-анимации
- script.js — частицы, реагирующие на движение мыши, и лёгкий 3D-наклон круга
- assets/max-hero.jpeg — исходное изображение пользователя

Как открыть:
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Откройте index.html и нажмите правой кнопкой → Open with Live Server (если расширение установлено).
   Либо дважды нажмите index.html, чтобы открыть его в браузере.
4. Для публикации загрузите содержимое папки на статический хостинг.
